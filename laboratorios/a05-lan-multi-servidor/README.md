# A05 — LAN com Múltiplos Servidores e Balanceamento de Serviços

**Disciplina:** SSC0540 — Redes de Computadores | **Tipo:** Laboratório (Cisco Packet Tracer)

## Objetivo

Implementar uma LAN com múltiplos servidores, distribuindo serviços de rede entre eles, e adicionar conectividade sem fio com dispositivos móveis.

## Topologia

- **Servidor 1:** HTTP + DNS
- **Servidor 2:** DHCP + e-mail (SMTP)
- Wi-Fi: Access Point com laptop adicional

## Conceitos praticados

- Configuração de múltiplos serviços em servidores distintos
- **Balanceamento de funções** entre servidores: separação entre servidor web/DNS e servidor DHCP/e-mail
- Configuração de DNS necessária para o funcionamento do serviço de e-mail
- Rede sem fio (Wi-Fi): adição de dispositivos à rede existente
- **Troubleshooting**: resolução de problemas como etapa essencial do laboratório

## Ferramentas

- Cisco Packet Tracer

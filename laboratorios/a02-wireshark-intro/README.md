# A02 — Introdução ao Wireshark e Análise de Pacotes

**Disciplina:** SSC0540 — Redes de Computadores | **Tipo:** Laboratório (Wireshark)

## Objetivo

Introdução à análise de tráfego de rede com Wireshark, observando pacotes reais de protocolos como DNS, HTTP e DHCP.

## Conceitos praticados

- Captura de pacotes em interface de rede
- Filtros de captura e de exibição no Wireshark
- Identificação de protocolos na pilha TCP/IP
- Visualização de campos de cabeçalho (Ethernet, IP, TCP/UDP)

## Ferramentas

- Wireshark

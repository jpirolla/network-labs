# A07 — Interconexão de Redes (variação)

**Disciplina:** SSC0540 — Redes de Computadores | **Tipo:** Laboratório (Cisco Packet Tracer)

## Objetivo

Projetar e implementar uma infraestrutura de rede com duas sub-redes interligadas por roteador e backbone de fibra óptica, com serviços distribuídos entre servidores dedicados.

Atividade de mesma especificação que o [a03](../a03-interconexao-redes/), realizada em data diferente (27/mar) com implementação independente.

## Conceitos praticados

- Interconexão entre redes `192.168.1.0/24` e `192.168.2.0/24`
- Roteamento entre sub-redes
- DHCP relay com `ip helper-address`
- DNS, HTTP e e-mail em servidores separados
- Backbone com fibra óptica

## Ferramentas

- Cisco Packet Tracer

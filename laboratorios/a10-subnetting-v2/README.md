# A10 — Subnetting VLSM (segunda iteração)

**Disciplina:** SSC0540 — Redes de Computadores | **Tipo:** Laboratório (Cisco Packet Tracer)

## Objetivo

Segunda iteração do exercício de subnetting com VLSM. Mesma especificação do [a09](../a09-subnetting-vlsm/), implementada com arquivo Packet Tracer independente.

## Conceitos praticados

- Divisão de `192.168.1.0/24` em 5 sub-redes (3×/26, 1×/27, 1×/30)
- VLSM e cálculo de endereçamento
- Verificação de não sobreposição entre sub-redes

## Ferramentas

- Cisco Packet Tracer

# A08 — VLSM com RIP v2 (variação)

**Disciplina:** SSC0540 — Redes de Computadores | **Tipo:** Laboratório (Cisco Packet Tracer)

## Objetivo

Implementar rede com VLSM e RIP v2, mesmo escopo do [a04](../a04-vlsm-rip/). Atividade realizada como segunda iteração do exercício.

## Conceitos praticados

- **VLSM** — subdivisão com LAN 1 (`/26`), LAN 2 (`/26`), Link entre roteadores (`/30`)
- **RIP v2** — protocolo de roteamento dinâmico, sem auto-summary
- DHCP relay com `ip helper-address` para redes remotas
- DNS para resolução de nomes entre redes

## Nota

Esta atividade não possui arquivo `.pkt` — apenas o enunciado foi preservado.

## Ferramentas

- Cisco Packet Tracer

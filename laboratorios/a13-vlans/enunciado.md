## Projetos a Implementar

### 1. VLANs (Switch Layer 2) com Router-on-a-Stick e DHCP no Roteador
- Implementar a segmentação de redes por VLANs utilizando Switch Layer 2.
- Configurar subinterfaces 802.1Q no roteador para o roteamento inter-VLAN (*Router-on-a-Stick*).
- Configurar pools DHCP no próprio roteador para distribuição dinâmica de IPs.
- **Link do vídeo de apoio:** [http://bit.ly/44w7wKV](http://bit.ly/44w7wKV)

### 2. VLANs com Switch Layer 3 (Multilayer Switch) e DHCP
- Implementar a segmentação de VLANs e roteamento inter-VLAN diretamente no Switch Layer 3 via SVIs (*Switched Virtual Interfaces*).
- Configurar os serviços de DHCP para cada VLAN.
- **Link do vídeo de apoio:** [https://bit.ly/452Nc41](https://bit.ly/452Nc41)

### 3. Integração de Servidor DNS
- Implementar um servidor DNS dedicado na topologia e associá-lo aos projetos, garantindo que todos os hosts recebam o endereço IP do DNS via DHCP e consigam resolver nomes internos.

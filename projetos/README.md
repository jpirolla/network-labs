# Projetos Acadêmicos — SSC0540 Redes de Computadores

Projetos completos desenvolvidos como avaliações da disciplina **SSC0540 — Redes de Computadores** (ICMC/USP, 2026).

Ambos os projetos consistem em projetar e implementar a infraestrutura de rede de uma empresa fictícia (**Kodalabs**), com relatório técnico justificando as decisões arquiteturais.

---

## Projetos

| Projeto | Título | Principais conceitos |
|---------|--------|----------------------|
| [Projeto 1](./projeto1-rede-corporativa/) | Rede Corporativa para a Kodalabs | VLAN, VLSM, OSPF, Router-on-a-Stick, DHCP relay, DNS, HTTP, FTP, SMTP |
| [Projeto 2](./projeto2-wan-multiarea/) | Expansão WAN com OSPF Multi-área e IoT | OSPF multi-área (ABR), Data Center privado, IoT, VLAN, VLSM |

---

Os projetos são progressivos: o Projeto 2 é uma evolução direta do Projeto 1, expandindo a topologia e adicionando novos requisitos.
